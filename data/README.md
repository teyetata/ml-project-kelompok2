# Data

Dataset bersumber dari repositori terbuka dengan lisensi CC BY 4.0, sehingga berkasnya boleh disalin dengan atribusi yang sesuai. Rujukan resmi:

- **Nama dataset:** Municipal waste management cost and fee schemes
- **Penyedia:** Bicocca Open Archive Research Data (kontributor: Giacomo Di Foggia)
- **Tautan:** https://board.unimib.it/datasets/w5f9kg7743/1
- **DOI:** 10.17632/w5f9kg7743.1
- **Lisensi:** CC BY 4.0

## Cara memakai

1. Unduh berkas data dan `read_me.txt` dari tautan di atas.
2. Simpan berkas data sebagai `data/public_data_waste_fee.csv` (dan `read_me.txt` di folder yang sama).
3. Ubah `DATA_PATH` pada sel Bagian 0 di `notebooks/ML_final.ipynb` ke jalur berkas tersebut. Bawaan notebook: `/content/public_data_waste_fee.csv` untuk Google Colab.

Jika berkas CSV ikut diunggah ke repository ini, notebook dapat dijalankan langsung dari repository.
